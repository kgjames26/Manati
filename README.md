# MANATI — Gardiens de la Terre

Jeu de plateforme 3D web, conçu pour PC et mobile avec React, TypeScript, Vite, Three.js, React Three Fiber et Rapier.

## Démarrer

```bash
npm install
npm run dev
```

## Compiler

```bash
npm run build
npm run preview
```

Le dossier `dist` est prêt pour Vercel. Le dépôt utilise Vite : commande de build `npm run build`, dossier de sortie `dist`.

## Commandes

- PC : flèches ou A/D pour courir, Espace pour sauter, E pour le pouvoir, Q pour appeler les héros.
- Mobile : boutons tactiles à l’écran.
- Pause : bouton en haut à droite.

La progression et l’âge sélectionné sont enregistrés dans le navigateur. MANATI comprend 80 missions, trois profils de joueurs, sept tenues à pouvoirs distincts, ennemis, plateformes, sauts, appel d’alliés, santé, difficulté selon l’âge et paramètres graphiques.
